# Advanced Time Series Forecasting with Attention Based Neural Networks

## Overview
This project implements an attention-based deep learning model for time series forecasting.

## Objectives
- Data preprocessing
- Attention based neural network
- Rolling origin cross validation
- Model evaluation
- Forecasting pipeline

## Technologies
Python, NumPy, Pandas, TensorFlow, Scikit-learn

## How to Run
pip install -r requirements.txt
Run notebook
